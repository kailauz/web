# kailauz-web

Лендинг Kailauz на Next.js с формой листа ожидания. Деплоится на Vercel из ветки `main`.

## Состав репозитория

| Путь | Назначение |
|---|---|
| `pages` | Страницы на русском и английском, политика, условия и `api/waitlist` |
| `components`, `lib`, `styles` | Компоненты, тексты и стили |
| `public` | Изображения и файлы для поисковиков |
| `scripts/indexnow.mjs` | Уведомление поисковиков о новых страницах |

## Разработка

```bash
yarn install
yarn dev
yarn build
```

Лист ожидания пишет в Supabase через серверный ключ `SUPABASE_SERVICE_ROLE_KEY`. Переменные окружения задаются в настройках проекта на Vercel. Причины отказа записи видны в логах Vercel по событиям `waitlist.*`.
